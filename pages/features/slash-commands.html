Slash commands

Type / as the first character in the composer to open the command palette - a floating list that filters as you type. It is the fastest way to run chat actions, switch model or persona, manage memory, fetch a URL and more without lifting your hands off the keyboard.

The command palette

The palette opens whenever the composer text starts with / and narrows to the commands whose names begin with what you type - /re leaves /rename, /regenerate and /remember. Each row shows the command, its arguments and a one-line description, under the same group headers /help uses (the headers appear once the list spans more than one group). A command with a fixed set of arguments lists them as rows of their own once you’ve typed its full name: /list offers /list models, /list snippets and the rest, and /instructions offers /instructions clear. Enter then completes the highlighted row, so to run a bare /instructions, press Esc to hide the palette first.

  • ↑ / ↓ - move the selection through the filtered list. It wraps around at either end.
  • Tab - complete the highlighted command without running it.
  • Enter - complete a partial command, or run one that is already fully typed. Shift + Enter still inserts a newline.
  • Esc - hide the palette for the current draft. It comes back once you delete the leading / and type it again.

Clicking a row completes it, like Tab. Anything that isn’t a recognised command is sent as an ordinary message, so a prompt that happens to start with / is never swallowed. Commands run even while a reply is streaming; the few that can’t, such as /regenerate, say so. Private Chat has no command palette - a leading / there is just text.

Where the results appear

A command that does something confirms with a short toast (Renamed chat, Switched model). One that fails says why in a Command failed toast - for example No active chat. Start one with /new first. when a command needs an open chat and none is open. Commands that return a list - /list, /tools, /fetch, /stats, a bare /instructions, or a name that matches several things - show it in a panel just above the composer. Close the panel with its ×; sending your next message clears it too.

The commands

Commands are grouped the way /help lists them. <arg> is required, [arg] optional. Most act on the chat that is open.

Chat

CommandWhat it does
/newStart a new chat. It lands in the active Space when there is one (the Space you’re viewing, or one picked with /space).
/clearDelete every message in the current chat, after a confirmation. A reply still streaming in that chat is stopped first.
/rename <title>Rename the current chat. The whole rest of the line is the title.
/pinPin the current chat, or unpin it if it’s pinned.
/archiveMove the current chat to the archive, with an Undo in the toast.
/deleteDelete the current chat permanently, after a confirmation.
/forkFork the chat into a new copy and open it.
/regenerateRe-stream the last assistant reply. Refused when the last turn isn’t an assistant reply, the reply was imported, the chat has no model, or the chat is still busy.
/copy [N]Copy the latest assistant reply to the clipboard, or the Nth-latest - /copy 2 is the one before it. Only assistant replies count, and N must be a positive whole number.
/exportOpen the Export context dialog for this chat.
/statsShow the chat’s message counts, total tokens and average tokens/sec across replies, the last reply’s numbers, and the model.
/compactSummarise older messages to free context - see Context & compaction. Only one chat compacts at a time.
/privateOpen Private Chat. A reply streaming in a regular chat is stopped first.

Model & persona

CommandWhat it does
/model <name>Switch the current chat’s model. An exact model id or display name wins; otherwise every model whose id or name contains what you typed matches, and several matches are listed so you can be more specific.
/persona <name>Apply one of the built-in personas to the current chat, matched the same way by name. /persona none clears it.

Listings

CommandWhat it lists
/list modelsEvery model from both providers, with its provider.
/list personasThe built-in personas and what each does.
/list spacesYour Spaces, marking the active one.
/list snippetsYour Snippets, with any pinned model and the start of the prompt.
/list mcpYour MCP servers, enabled or disabled, and how each connects.
/list providersThe Ollama and OpenAI-compatible base URLs, and whether an API key is saved.
/list memoriesThe memories /remember and /forget work on (see below), each with the short id /forget accepts.

Prompts

CommandWhat it does
/instructions <text>Set the current chat’s own instructions - the Additional instructions in the parameters panel. Line breaks are kept.
/instructions clearClear them.
/instructionsOn its own, show the chat’s current instructions. A compaction summary stored with them is kept whichever form you use.
/snippet <name>Put a saved Snippet into the composer, matched by title, with its variables filled in. Any blanks left open the fill-in dialog first. Unlike a Snippet’s Run, it stays in the current chat and doesn’t switch model.

Memory & spaces

The memory commands work on one list: the open chat’s Space; for a chat outside any Space, the active Space if there is one; otherwise your global memories. See Spaces and Memory.

CommandWhat it does
/remember <fact>Save a fact to that list. Refused when the Space’s memory is switched off - or, outside a Space, while Settings → Features → Global memories is off.
/forget <id|query>Remove a memory by its id (at least the eight characters /list memories shows) or by text it contains. When several match the text, they’re listed so you can re-run with an id.
/space <name>Make a Space active, matched by name. /new then starts its chat there, and the memory commands use that Space outside a Space chat.

Tools & web

CommandWhat it does
/toolsList the tools exposed by your enabled MCP servers, server by server; a server that can’t be reached shows its error. Built-in tools aren’t listed.
/web-fetch on|offTurn Web fetch on or off for every chat - the same switch as in Settings → Tools.
/fetch <url>Fetch one page now and show its final URL, title, size and the first 200 characters of its text - a quick way to see what Web fetch would get. It works with the Web fetch switch off and goes through the same safety checks.
/thinking on|offTurn the current chat’s Thinking toggle on or off (Ollama models that can reason).

App

CommandWhat it does
/settings [tab]Open Settings, optionally on a tab: general, providers, features, tools, appearance, mcp, archive, data, security, updates or about.
/helpOpen the Slash commands reference, with every command grouped as above.

Recent commands

Above those groups sits a Recent group: up to four of the commands you ran last that match what you’ve typed, hoisted out of their normal groups. Loach keeps the last six command names in its settings rather than per session, so the group is useful on the first / after a restart instead of only once you have already run a command that launch. A command counts even if it failed - you’re likely to retry it - while text that isn’t a command is never recorded. Argument rows such as /list models stay where they are.

Destructive commands confirm first

/clear and /delete route through a confirmation dialog before they run, so a mistyped command can’t wipe a conversation by accident. The dialog’s confirm button has focus, so Enter confirms and Esc cancels. /archive doesn’t ask - it offers Undo instead.
