Spaces

A Space is a long-lived workspace built around a project: a codebase, a research question, an ongoing piece of writing. It bundles instructions, reference sources, a memory and a default model. Every chat created inside a Space inherits that context automatically.

What a Space holds

  • Instructions - a system prompt for every chat in the Space. When set, it replaces both your global custom instructions and the chat’s own instructions.
  • Reference sources - text files, PDFs and Word documents are inlined into the system prompt of every chat in the Space; images ride along with each message so vision-capable models can see them. See Reference sources below.
  • Memory - facts about you that Loach learns from the Space’s chats. See Memory.
  • Default model - the provider and model new chats in the Space start with, so a “code review” Space can always start in a different model than a “writing” Space.

Creating and editing

Open the Spaces tab in the sidebar and click New space. Give it a name (up to 60 characters) and an optional description, then Save - Loach opens the new Space. The library shows every Space as a tile, most recently updated first, with its chat count, a New chat button and a … menu (Open / edit, Delete).

A Space’s page shows its description, a row of chips summing it up (chats, sources, Instructions on, memories, model) and a composer: type there to start a new chat in the Space. Below it are five tabs:

  • Chats - the Space’s chats, grouped by Today, Yesterday, Earlier this week and Older. Archived chats aren’t listed. Each row’s … menu (or a right-click) offers the same actions as the main sidebar: Pin this chat / Unpin, Label, Rename, Move to archive and Delete.
  • Instructions - the Space’s system prompt. It’s saved when you click away from the field.
  • Sources - add and remove reference sources.
  • Memory - the Space’s memory switch and its memory editor.
  • Models - the default model for new chats in the Space. Leave it empty (or pick Clear selection) to use your default model from Settings → General. Switching model inside a chat still wins.

Rename the Space or change its description from the … menu next to its title → Edit details. Changes to instructions, sources and memory reach every chat in the Space with its next message.

Besides the composer on the Space’s page and the New chat button on its tile, you can type /space <name> to make a Space active, then /new to start a chat in it.

Deleting a Space

Pick Delete space from the … menu (or Delete on its library tile). The Space’s instructions, sources and memory are deleted. Its chats are kept: they leave the Space and carry on as regular chats.

Reference sources

Add files on the Sources tab with Add source. Every source is sent with every message in the Space:

  • Text and code files - inlined into the system prompt.
  • PDFs and Word (.docx) documents - their text is extracted and inlined. A scanned PDF has no text to extract; add its pages as images instead.
  • Images - PNG, JPEG, WebP and GIF are attached to each message for vision-capable models.
  • Anything else - formats Loach can’t read, such as legacy .doc files or archives, are stored but never sent to the model.

Each file can be up to 20 MB, and a Space’s sources up to 200 MB in total; the tab shows how much is used. A file’s text is cut off after about 200,000 characters, with a note telling the model so. Because sources go out with every message, large ones use a lot of context on every turn. The context-usage bar doesn’t count them, so in a Space with big sources it reads lower than what the model actually gets.

Space memory

Each Space has its own memory, on by default for a new Space. After every finished reply in the Space, Loach asks the chat’s model to pick out lasting facts about you, saves them, and adds them to the system prompt of every chat in the Space as a --- Space memory --- list. A toast with an Undo button announces every change.

Turn memory off with the switch on the Memory tab: Loach stops saving new facts, but the ones already saved are still sent until you delete them. How capture, updates, limits and /remember work - and how Space memory combines with global memories - is covered on the Memory page.

When to make a Space

Reach for a Space whenever you find yourself opening several chats that share the same reference files or the same instructions. The cost is one click; the upside is never re-pasting context again.
