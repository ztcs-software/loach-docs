Keyboard shortcuts

Loach is keyboard-friendly. Press Ctrl + / to open an in-app cheat sheet of the nine app-wide shortcuts below; the dialog and the handler read the same table, so the keys listed there are the keys the app actually listens for. The composer, palette and finder keys further down aren’t in it. On macOS, ⌘ stands in for Ctrl throughout, and the cheat sheet shows ⇧ for Shift.

Navigation

  • Ctrl + K - open the search palette across chats, messages, Spaces and Snippets.
  • Ctrl + N - start a new chat outside any Space.

Chat

  • Ctrl + F - find within the current chat transcript, with browser-style match highlighting and a match counter. Does nothing unless a chat with at least one message is on screen.
  • Ctrl + U - attach files to the current chat (opens the file picker).
  • Ctrl + Shift + Backspace (or Delete) - delete the current chat, after a confirmation.

Layout

  • Ctrl + Shift + S - show or hide the left sidebar.
  • Ctrl + Shift + P - show or hide the parameters panel while a chat is open.

Security

  • Ctrl + Shift + L - lock Loach now, when an app lock is configured. It works in Private Chat and during onboarding too.

Help

  • Ctrl + / - open the keyboard-shortcuts cheat sheet, or close it again.

In the composer

  • Enter - send the message, or run the typed slash command.
  • Shift + Enter - insert a newline without sending. Use this for multi-paragraph prompts.
  • / - typed as the first character, opens the slash-command palette.

In the slash-command palette

  • ↑ / ↓ - move through the filtered command list. The selection wraps around at either end.
  • Tab - complete the highlighted command.
  • Enter - run a fully-typed command, or complete a partial one.
  • Esc - dismiss the palette for the current draft. Anything that isn’t a recognised command is sent as an ordinary message.

In the search palette

  • ↑ / ↓ - move between results.
  • Enter - open the highlighted result. A chat opens the conversation; a message opens its chat and jumps to that turn; a Space opens its detail view; a Snippet starts a fresh chat with the snippet’s prompt primed in the composer.
  • Tab - move between the palette’s controls. Focus stays inside the palette until you close it.
  • Esc - clear the query, then close the palette on a second press.

In the in-chat finder

  • Enter or ↓ - jump to the next match.
  • Shift + Enter or ↑ - jump to the previous match. Both directions wrap around.
  • Esc - close the finder and clear the highlights.

In fields and dialogs

  • Enter - save a rename (a chat in the sidebar, the chat header or a Space’s chat list); Esc cancels it.
  • Enter - in the memory editor, add or save a fact (Shift + Enter for a newline while editing); Esc cancels an edit.
  • Enter - in a Snippet’s fill-in dialog, move to the next blank; on the last one, put the filled-in prompt in the composer.
  • Enter or Space - open a focused chat row, folder, Space, Snippet or model tile, or attachment chip.
  • Enter / Esc - in a confirmation dialog, confirm or cancel. The confirm button has focus when the dialog opens - including for deletions.

Where shortcuts do not apply

The app lock screen blocks every shortcut and the search palette. While the onboarding wizard or Private Chat owns the window, the app-wide shortcuts and the search palette are off too - except Ctrl + Shift + L, which locks Loach from anywhere. Esc still dismisses menus and dialogs, and exits onboarding (with a confirm on the provider step). It does not close Private Chat: only the × in its header does, so a stray key can’t wipe the conversation. The web view’s own find bar (Ctrl + G, F3) is switched off - use Ctrl + F.
