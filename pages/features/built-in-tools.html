Built-in tools

A set of small, local utilities the model can call mid-answer through the same tool-call loop as MCP. They run entirely in Rust on your machine - no network, and apart from the file tools, nothing that touches your files - so they also work inside Private Chat.

How they work

Each tool has its own switch in Settings → Tools, and every one is off by default - turn on only what you want a given model to reach for. The onboarding wizard’s Tools step proposes a Recommended set (everything except the four developer-only tools - Hash, UUID, Base64 and IP / CIDR - and Workspace files, which switches itself on when you pick a folder) with All OFF / Recommended / All ON presets. Continue saves the switches exactly as shown; Skip saves only the ones you changed.

When the model uses a tool, the call shows up in a collapsible block above the answer - “Called N tools”, or “Called calculate tool” for a single call - where you can inspect its arguments and result. Built-in tools never ask before they run; the only exceptions are the file tools that change files (see below).

Loach offers the switched-on tools to whichever model you are chatting with, so the model has to support tool calling to use them. Many local models do, but not all - with Ollama, a model without tool support fails the request with an error saying it does not support tools. Pick a different model, or switch the tools off.

The tools

Each entry gives the switch’s name in Settings → Tools, then the tool name the model sees.

  • Calculator (calculate) - evaluate arithmetic, trigonometry (in radians), functions such as sqrt, ln, log10 and round, and the constants pi and e. Operators group the way programming languages do (100 / 5 * 2 is 40, 2^3^2 is 512), % is the remainder, and scientific notation such as 6.022e23 works.
  • Date & time (datetime) - parse, format and do arithmetic on dates and times, with DST-aware timezone conversion, weekday lookup and business-day counting (Saturdays and Sundays are skipped; holidays are not).
  • Count (count) - count characters, bytes, words, lines or substring hits.
  • Hash (hash) - SHA-224 / 256 / 384 / 512 over UTF-8, hex or base64 input.
  • UUID (uuid) - generate v4 (random) or v7 (time-ordered) UUIDs, up to 100 per call.
  • Base64 (base64) - encode and decode with the standard or URL-safe alphabet.
  • JSON (json) - validate, pretty-print, or pull values out by JSON Pointer.
  • Unit conversion (unit_convert) - convert between units across nine categories: length, mass, volume, speed, time, area, energy, pressure and temperature, including less common units such as furlongs, troy ounces and parsecs.
  • Text diff (diff_text) - unified diff between two strings, by line, word or character.
  • Sort (sort) - sort lines lexically, naturally (file2 before file10) or numerically, with reverse, unique and case-insensitive options.
  • IP / CIDR (ip) - CIDR membership checks and subnet info (network, broadcast, first and last usable host, host count), for IPv4 and IPv6.
  • PDF (pdf) - generate a downloadable PDF from a structured spec (see below).
  • Workspace files - one switch for eight file tools that let the model work in a folder you pick for a chat. They are the only built-in tools that touch the disk, and they have their own page.

Web fetch has a switch on the same tab but is not a tool the model calls: Loach fetches the URLs in your message before the request goes out.

PDF generation

The pdf tool turns a structured spec - headings, paragraphs, bulleted and numbered lists, simple tables, horizontal rules and page breaks - into a real A4 PDF. The result lands in the chat as a previewable, savable attachment, so you can ask the model to draft a document and pull it straight out. The bundled font covers Latin text, European accents and common punctuation and currency symbols; characters outside it, such as CJK or emoji, come out as ?. Images and merging existing PDFs are not supported.

Limits

  • 20 seconds per call - a built-in tool that runs longer is stopped and the model is told to try smaller input. The file tools that change files are the exception: they always run to the end.
  • 32 KB back to the model - a longer result is cut, with a note telling the model so; the tool-call block still shows the whole result.
  • 10 rounds per reply - tools can run in the first nine rounds with the model; the tenth goes out without tools so the model wraps up. See “Stopped after 10 tool-use turns”.
Local and private

Built-in tools never touch the network, and only the file tools touch your files. That is why they remain available inside Private Chat, where MCP tools are blocked. The file tools are the one exception: Private Chat never gets a folder, so it never gets them either.
